JSONL: The Format We Didn't Know We Needed📖 Texto completo

Dave TaublerLevel Up Coding ()24 de octubre de 2026
desarrollofrontend

JSONL cambia una sola cosa respecto a JSON: cada objeto completo ocupa una línea independiente. Esa decisión permite leer, procesar y añadir registros sin cargar un array entero en memoria; para un fichero de 50 MB, un parser con buffering puede necesitar todo el documento, mientras JSONL necesita esencialmente el registro mayor. El formato resulta especialmente adecuado para logs, telemetría, colas, entrenamiento y pipelines ETL.

Su ventaja no es solo técnica sino de ecosistema: Spark, Hadoop, pandas con read_json(lines=True), jq, Elasticsearch, Logstash y herramientas de datasets ya lo entienden. También facilita particionar y procesar en paralelo. No debe sustituir a JSON en APIs REST, configuraciones pequeñas o documentos anidados; allí JSON conserva sus convenciones y estructura. La recomendación es elegir JSONL cuando los datos llegan como eventos independientes y se benefician del streaming.

The Best API Change Is the One Nobody Notices📖 Texto completo

Michael LongThe Swift Cooperative ()24 de octubre de 2026
desarrollofrontend

Factory necesitaba contenedores dependientes de la escena sin romper la API pública basada en tipos. La solución no añade un parámetro genérico a cada wrapper: guarda en un único valor del entorno un diccionario de contenedores indexado por ObjectIdentifier del tipo. Las resoluciones de un tipo instalado usan la instancia de la escena; las no instaladas caen a C.shared, preservando el comportamiento anterior.

El cambio conserva rutas públicas como environment container y los mismos inicializadores, y añade sobrecargas de withContainer para tipos, key paths y contenedores completos. InjectedContainer pasa a DynamicProperty para leer el entorno solo durante update(), evitando advertencias en view models. El autor señala límites: wrappers estáticos y lecturas en init no ven el entorno, la identidad duplicada entre módulos puede ser problemática y el fallback silencioso oculta errores. Es un ejemplo de evolución compatible: mover variación a datos en vez de al tipo.
